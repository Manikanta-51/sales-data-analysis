# Charts

This folder contains all the generated visualizations from the analysis.

| File | Description |
|---|---|
| `sales_by_category.png` | Bar chart — Revenue by Category |
| `subcategory_comparison.png` | Grouped bar — Sales & Profit by Sub-Category |
| `region_pie.png` | Pie chart — Regional Sales Distribution |
| `top_products.png` | Horizontal bar — Top 10 Products by Revenue |
| `monthly_trend.png` | Line chart — Monthly Sales Trend by Year |
| `profit_heatmap.png` | Heatmap — Monthly Profit Pattern |
| `sales_vs_profit.png` | Scatter plot — Sales vs Profit by Category |
| `loss_products.png` | Bar chart — Top 10 Loss-Making Products |

> Charts are generated automatically when you run `sales_analysis.py` or the Jupyter Notebook.
